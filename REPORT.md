# Отчет по лабораторной работе №8

## Тема

Использование Docker для сборки и запуска C++ приложения.

## Цель работы

Создать Dockerfile, собрать Docker-образ и запустить приложение с подключенным каталогом для логов.

## Выполненные действия

1. Создано приложение `demo` на C++.
2. Добавлен `CMakeLists.txt` для сборки и установки приложения.
3. Добавлен `Dockerfile`.
4. В Dockerfile задана переменная окружения `LOG_PATH`.
5. Добавлен volume `/home/logs`.
6. В качестве точки входа используется `./demo`.
7. Добавлен `.travis.yml`, который собирает Docker-образ.

## Команды проверки

```sh
docker build -t logger .
mkdir -p logs
docker run -it -v "$(pwd)/logs/:/home/logs/" logger
cat logs/log.txt
```

## Ожидаемый результат

После запуска контейнера пользователь вводит строки. После завершения ввода строки сохраняются в файл `logs/log.txt`.

Пример содержимого файла:

```text
text1
text2
text3
```

## Проверка Travis CI

Файл `.travis.yml` включает сервис Docker и выполняет сборку образа:

```sh
docker build -t logger .
```
